# Contributing to Resetting World (`resettingworld.com`)

Welcome! Resetting World is a community-driven open-source initiative with three pillars:
- [`rw-knowledge`](https://github.com/resettingworld/rw-knowledge) — Offline AI & Knowledge Capsules (`<= 50` books/pack)
- [`rw-protocol`](https://github.com/resettingworld/rw-protocol) — Decentralized DTN/Mesh Protocol & Pluggable Apps
- [`rw-hardware`](https://github.com/resettingworld/rw-hardware) — Solar, LiFePO4 & Open Hardware Blueprints

## Quick Guidelines
1. Keep every core runtime feature **100% offline-first** (no cloud API dependencies at query/runtime).
2. Read the `AGENTS.md` and `README.md` in each repository before submitting changes.
3. Follow the `CODE_OF_CONDUCT.md` and report security/safety issues privately per `SECURITY.md`.
4. Submit Pull Requests with tests (`pytest` / `cargo test`) and clear verification steps.
